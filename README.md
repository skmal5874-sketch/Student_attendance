# نظام إدارة حضور الطلاب

مشروع واجهة ويب باللغة العربية، باستخدام HTML وCSS وJavaScript فقط.

## الملفات
- `index.html`: صفحة تسجيل الدخول.
- `attendance.html`: نموذج تسجيل حضور الطلاب.
- `records.html`: عرض السجلات وتنزيلها بصيغة CSV.
- `README.md`: شرح المشروع.

## الرفع إلى GitHub
1. أنشئي مستودعاً جديداً باسم `student-attendance`.
2. ارفعي الملفات الثلاثة وملف README إلى جذر المستودع.
3. افتحي Settings ثم Pages.
4. اختاري Deploy from a branch، ثم `main` و`/(root)`، وبعدها Save.

## ملاحظة مهمة
هذا نموذج تجريبي ثابت. تُحفظ السجلات في `localStorage` داخل المتصفح الذي أُدخلت فيه فقط، ولا تُشارك بين الأجهزة أو المستخدمين. صفحة الدخول لا تتحقق من كلمة المرور. للاستخدام الحقيقي تحتاجين إلى خادم وقاعدة بيانات ونظام صلاحيات.
